# 📰 每日资讯抓取 —— 使用说明

> 自动帮你抓：梦幻西游 × 8 条 + AI资讯 × 8 条 + 兰花知识 × 8 条 ≈ 每天 24 条
> 每天早上 **8:00** 自动生成一份当天的新闻页面，手机电脑都能看。

---

## 🚀 第一次使用：三步走

### 第1步 · 注册"每天8:00自动抓"的定时任务

双击 `注册每日抓取任务.bat`
- （建议右键 → **以管理员身份运行**，否则可能权限不够）
- 注册成功后会**立即测试抓一次**，让你看到效果

想卸载？打开 cmd 输入：
```
schtasks /delete /tn "创作者工作台_每日资讯抓取" /f
schtasks /delete /tn "创作者工作台_每日资讯抓取_开机补抓" /f
```

### 第2步 · 启动本地网页服务（手机才能访问）

双击 `启动服务_手机访问.bat`
- 窗口保持开着不要关（关了服务就停了）
- 电脑打开：`http://localhost:8088/news_pages/index.html` 就能看到新闻列表

### 第3步 · 手机打开看

**两种方法任选一种（推荐 A）**

| 方式 | 操作 | 说明 |
|---|---|---|
| **A. 同一WiFi局域网**（最稳）| 1. 先看电脑IP：在服务窗口开的状态下，cmd 输入 `ipconfig`，找到 IPv4（比如 `192.168.1.20`）<br>2. 手机连上同一个WiFi<br>3. 手机浏览器访问：`http://192.168.1.20:8088/news_pages/` | 不用装任何软件，延迟为0 |
| **B. 异地4G/5G查看**（cpolar内网穿透）| 1. 去 https://www.cpolar.com 免费注册账号<br>2. 下载 cpolar.exe 到同一目录<br>3. 启动服务后新开一个窗口运行：`cpolar http 8088`<br>4. 控制台会显示类似 `https://xxx.cpolar.io` 的地址，手机输这个就行 | 免费版每次重启地址会变，出门偶尔看看用这个 |

## 📁 生成的文件在哪？

```
📁 工作目录/
├─ news_fetcher.py              ← 爬虫脚本（不要改）
├─ 注册每日抓取任务.bat          ← 第1步：双击注册定时任务
├─ 启动服务_手机访问.bat         ← 第2步：双击开网页服务
│
├─ 📂 news_data/                 ← 每日原始数据（JSON）
│   └─ news-2026-08-16.json
│
└─ 📂 news_pages/                ← 每日生成的HTML页面（手机/电脑看的）
    ├─ index.html                ← ★ 新闻列表总入口 ★
    ├─ news-2026-08-16.html      ← 8月16日的新闻
    ├─ news-2026-08-17.html      ← 8月17日的新闻
    └─ ...
```

## ❓ 常见问题

**Q：早上8点电脑没开机，会漏抓吗？**
A：不致命。我额外注册了「开机后30分钟补抓」的计划任务，你一开机它就自动补抓当天的；或者你任何时候手动 `python news_fetcher.py` 跑一次也行。同一天多次运行不会重复存（JSON是直接覆盖当天那份）。

**Q：梦幻/兰花/AI 少于8条？**
A：正常，周末/节假日源站更新少，脚本会尽量多抓但不硬凑垃圾内容。周一到周五工作日基本都是满的 8+8+8=24 条。

**Q：手机打开"无法访问此网站"？**
A：检查：① `启动服务_手机访问.bat` 这个黑窗口开着没？② 手机电脑是不是同一个WiFi？③ 电脑防火墙有没有阻止8088端口？

**Q：想改成每天7点抓 / 每类抓10条？**
A：`news_fetcher.py` 里：
- 抓几条：改 `PER_CATEGORY = 8` 那行
- 几点抓：不用改脚本，去 Windows 任务计划程序里改 `创作者工作台_每日资讯抓取` 这个任务的触发时间。
- 想加新源：改 `SOURCES` 列表，加一行配置进去就行。
